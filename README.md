# Toolbox Online — version 2

Plateforme front-end bilingue (français / anglais), responsive, avec recherche et filtres.

## 12 outils intégrés
1. Pourcentage
2. Loi d'Ohm
3. Puissance électrique
4. Conversion de longueurs
5. Conversion de masses
6. Conversion Celsius / Fahrenheit
7. Moyenne de notes
8. Note nécessaire pour atteindre une moyenne cible
9. Aire d'un triangle
10. Aire d'un rectangle
11. Vitesse moyenne
12. Masse volumique

## Lancer
Ouvrez `index.html` dans un navigateur. Aucun backend ni dépendance d'installation n'est requis.

## Publication gratuite avec GitHub Pages
1. Créez un dépôt public GitHub nommé `toolbox-online`.
2. Téléversez les fichiers `index.html`, `style.css`, `app.js`, `README.md` à la racine.
3. Allez dans Settings → Pages.
4. Sous Build and deployment, choisissez Deploy from a branch, branche `main`, dossier `/ (root)`, puis Save.
5. Attendez la publication. GitHub Pages affiche alors l'adresse du site.

## À personnaliser avant publication
- Remplacer `https://example.com/` dans la balise canonical par le vrai domaine.
- Remplacer `contact@example.com` par une adresse réelle.
- Ajouter une page confidentialité, des mentions légales et une page contact adaptées.
- Vérifier les calculs et l'interface sur plusieurs navigateurs et tailles d'écran.
- Créer du contenu explicatif original et utile autour de chaque outil pour le SEO.

## Important
Cette version est une application statique : pas de comptes, de base de données, de paiement, d'analytics ni de publicité. La rentabilité dépendra notamment de l'utilité, de la visibilité, du trafic et des coûts futurs; elle n'est pas garantie.
